---
title: Keyboard shortcuts
---

TimeTrove is designed so the everyday actions never need the mouse. On macOS, `Cmd/Ctrl` means <Kbd>⌘</Kbd>. On Windows, it means <Kbd>Ctrl</Kbd>.

## Anywhere

| Keys | Action |
| --- | --- |
| <Kbd>Mod+Shift+T</Kbd> | Open the task switcher. You can change this in [Settings](./settings.mdx) |

## Task switcher

| Keys | Action |
| --- | --- |
| Type | Filter tasks |
| <Kbd>↑</Kbd> <Kbd>↓</Kbd> | Move the highlight |
| <Kbd>Enter</Kbd> | Switch to the highlighted task, or start creating a task when nothing matches |
| <Kbd>Enter</Kbd> again | Confirm creating the new task |
| <Kbd>Ctrl+Tab</Kbd> | Cycle between Switch task, Add note and Link Jira |
| <Kbd>Esc</Kbd> | Close the switcher, or cancel replacing a Jira link |

## Gap prompt

| Keys | Action |
| --- | --- |
| <Kbd>1</Kbd> | Assign the gap to the previous task |
| <Kbd>2</Kbd> | Assign the gap to another task (opens search) |
| <Kbd>3</Kbd> | Discard the gap |
| <Kbd>↑</Kbd> <Kbd>↓</Kbd>, <Kbd>Enter</Kbd> | In search: choose a task, or create one |
| <Kbd>Esc</Kbd> | In search: go back to the three choices. On the choices it does nothing, because you must choose |

## Snooze picker

| Keys | Action |
| --- | --- |
| <Kbd>Enter</Kbd> | Start the snooze |
| <Kbd>Esc</Kbd> | Cancel |

## Day timeline

| Keys | Action |
| --- | --- |
| <Kbd>Tab</Kbd> | Move between resize handles |
| <Kbd>←</Kbd> <Kbd>→</Kbd> | Nudge the focused edge of an entry |
