title: Switching tasks
---

The switcher is the fastest way to start, change or create a task. Open it from anywhere with <Kbd>Mod+Shift+T</Kbd>, or click the clock on the tracker bar.

<Screenshot name="switcher-list" alt="Task switcher listing tasks, starred tasks first" width={420} caption="Starred tasks are listed first, then the rest alphabetically. Archived tasks are hidden." />

## Switch to an existing task

1. Open the switcher.
2. Type any part of the name. The list filters as you type.
3. Press Enter to switch to the highlighted task, or click any task.

Use <Kbd>↑</Kbd> and <Kbd>↓</Kbd> to move the highlight. Press <Kbd>Esc</Kbd> to close without changing anything.

<Screenshot name="switcher-search" alt="Switcher filtered by rev, showing Code review and Onboarding flow revamp" width={420} />

Switching ends the current time slice and starts a new one immediately.

## Create a task

Type a name that doesn't match any task and press Enter. TimeTrove asks you to confirm. Press Enter again to create the task with a fresh colour and start tracking it.

<Screenshot name="switcher-create" alt="Switcher asking to confirm creating Quarterly roadmap" width={420} />

## Other modes

The switcher has up to three tabs. Press <Kbd>Ctrl+Tab</Kbd> to cycle through them.

- **Switch task**: the default, described above.
- **Add note**: shown while tracking. Type a note for the current time slice and press Enter. Notes show up on the timeline tooltip and in the entries table.
- **Link Jira**: shown when the [Jira integration](../integrations/jira.mdx) is on. Lists open issues assigned to you. Pick one to link it to the current task. If the task already has an issue, you'll be asked to confirm replacing it.

## From the main window

The main window header always shows the current task and today's total, with **Switch** and **Stop** buttons. On the [Tasks](../tasks.mdx) tab, **Start** begins tracking the selected task.
